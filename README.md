# ColonyLab: Bio-Dota 🦠⚔️

Тактический симулятор борьбы штаммов бактерий в стиле Dota 2 на Canvas.

## 📂 Структура проекта

```
BioDota/
├── index.html        # Главный файл разметки (HUD, арена, модальные окна)
├── css/
│   └── style.css     # Dota 2 стилизация, анимации триумфа и талисманов
├── js/
│   ├── config.js     # Баланс характеристик штаммов, координаты карты и рун
│   ├── audio.js      # Процедурный синтезатор звуков на Web Audio API
│   ├── entities.js   # Классы: Bacterium, SuperBacterium, Neutral, Feeder
│   ├── ui.js         # Инспектор особей, SVG персонажи, графики популяций
│   └── main.js       # Игровой цикл, физика, рендер карты и обработка ввода
└── README.md         # Описание проекта
```

## 🚀 Запуск и публикация

1. **Локально**: Просто откройте `index.html` в любом современном браузере.
2. **GitHub Pages**:
   - Поместите файлы в корень или в ветку `gh-pages`.
   - В настройках репозитория в разделе **Pages** укажите источник (Deploy from a branch -> main / root).
   - Игра станет доступна по вашему адресу `https://charadzey.github.io/BioDota/`.
